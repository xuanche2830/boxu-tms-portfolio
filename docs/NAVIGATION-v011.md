# 页面和账号入口怎么分

v0.11 调整了导航：每天要看的运输和项目放在前面，成员、备份等管理操作收进设置。这样打开页面先看到要处理的票，不会被账号管理表单占满。实际检查结果见 [验证记录](VALIDATION.md)。

## 页面分工

| 入口 | 页面里做什么 | 谁会看到 |
| --- | --- | --- |
| 工作总览 | 看状态、异常和待办，直接进入单票 | 已登录成员 |
| 项目与需求 | 搜索项目、登记需求、分配运输 | 企业内部成员；货代不显示 |
| 运输委托 / 我的运输 | 筛选单号和状态，跟进已授权订单 | 企业成员 / 货代 |
| 业务资料 → 合作伙伴 | 维护伙伴名录；伙伴记录不等于登录账号 | 企业内部成员 |
| 业务资料 → 导入与待确认 | 检查来源文件；项目列表也有导入快捷入口 | 企业内部成员 |
| 企业设置 → 成员与权限 | 搜索名册、看操作记录 | 负责人 |
| 成员与权限 → 新增成员 / 成员详情 | 建账号，逐人分配或撤销业务授权 | 负责人 |
| 企业设置 → 数据与备份 | 导出、备份和恢复准备 | 负责人 |
| 侧栏姓名 → 个人账号 | 看自己的身份、改密或退出 | 已登录成员 |
| 运输委托 → 单票 → 凭证与复核 | 上传材料、看待补要求和复核结论 | 获授权成员 |

项目详情直接显示需求和关联委托；运输详情保留下一步动作。旧的 `#access`、`#maintenance`、`#imports` 链接会转到新路径，原项目和委托链接继续有效。

## 登录和账号管理

- 空白工作空间先提示设置企业负责人，点击“开始设置”后才出现表单。设置完成后，入口变成普通登录页。
- 成员管理默认展示名册，只有进入下一层才会看到新增表单。建好账号还要分配业务授权，成员才能看到对应项目或订单。
- 登录页支持显示密码、大写锁定提示和帮助说明。首次改密由服务端限制；页面隐藏入口不能代替接口权限检查。
- 停用账号或撤销授权前，成员详情会说明影响并要求确认，已有操作记录保留。
- 演示身份只属于合成演示空间。工作账号单独建立；货代侧栏主要显示工作总览和自己的运输。

## 自己走一遍

1. 负责人：企业设置 → 成员与权限 → 新增成员；取消返回名册；查看已有成员，核对组织和授权。
2. 员工：项目与需求 → 指定项目 → 登记需求 → 分配运输，或从总览待办直接进入运输。
3. 货代：我的运输 → 待接单 → 单票详情 → 接单/提交资料；不能看到企业设置。
4. 所有人：侧栏姓名 → 个人账号 → 修改密码；取消后返回账号页。
5. 再试刷新、浏览器前进后退和旧链接，确认位置与当前账号的可见范围；手机上也能展开导航。

## 还没做的账号能力

目前没有自助找回密码、自动发送邀请、企业单点登录或多企业切换。未保存表单的跨会话恢复、公网部署和完整无障碍审计也还需要单独设计与验收。
