# v0.11 导航与账号体验设计

目标：让日常运输和项目任务更容易进入，把低频管理收进设置。层级用于减少干扰，不以点击次数变多为目标。本文件描述设计，实际验收见本版验收记录。

## 页面分工

| 层级 | 入口 | 用途 |
| --- | --- | --- |
| 一级日常业务 | 工作总览 | 状态分布、异常与待办，可直接进入单票 |
| 一级日常业务 | 项目与需求 | 搜索项目，进入项目登记需求、分配运输；货代不展示该入口 |
| 一级日常业务 | 运输委托 / 我的运输 | 集中跟进已授权运输，筛选状态与单号 |
| 二级资料 | 业务资料 → 合作伙伴 | 业务伙伴名录，区别于登录账号 |
| 二级资料 | 业务资料 → 导入与待确认 | 处理来源文件；项目列表也保留导入快捷入口 |
| 二级管理 | 企业设置 → 成员与权限 | 名册、搜索、操作记录，仅负责人可见 |
| 三级管理 | 成员与权限 → 新增成员 / 成员详情 | 创建账号，查看状态及逐人分配/撤销业务授权 |
| 二级管理 | 企业设置 → 数据与备份 | 资料保全与恢复准备 |
| 个人入口 | 侧栏姓名 → 个人账号 → 修改密码 | 身份、业务范围说明、密码和退出 |
| 业务详情 | 运输委托 → 单票 → 凭证与复核 | 附件、待补资料与复核，保持业务上下文 |

项目详情仍然直接显示需求和关联委托；运输详情保留下一步动作，不要求返回首页找按钮。旧的 `#access`、`#maintenance`、`#imports` 链接转到新路径；原项目/委托链接继续有效。

## 账号边界

- 企业首次设置与日常登录区分：空库先显示初始化说明，只有选择开始设置才显示首个负责人表单；已初始化空间只显示账号登录。
- 成员名册是管理页默认视图，创建表单不常驻。账号创建后仍需业务授权。
- 登录支持密码显示/隐藏、键盘大写锁定提示和登录帮助；没有虚构短信、扫码、找回密码或自动发送邀请。
- 登录帮助解释账号分配、首次改密、停用及自助找回尚未提供。首次改密仍由后端限制，页面分层不替代接口权限检查。
- 停用账号或撤销权限前，在成员详情显示具体影响与确认操作。记录保留。
- 演示身份与工作账号分开；企业设置只对负责人显示，货代侧栏集中在工作总览和自己的运输。

## 可检验的使用路线

1. 负责人：企业设置 → 成员与权限 → 新增成员；取消返回名册；查看已有成员，核对组织和授权。
2. 员工：项目与需求 → 指定项目 → 登记需求 → 分配运输，或从总览待办直接进入运输。
3. 货代：我的运输 → 待接单 → 单票详情 → 接单/提交资料；不能看到企业设置。
4. 所有人：侧栏姓名 → 个人账号 → 修改密码；取消后返回账号页。
5. 浏览器刷新、前进后退和旧入口跳转，应保持位置与当前角色范围；手机需能展开导航。

## 本轮不作出的成熟度承诺

账号恢复、自动邀请发送、企业单点登录、多企业切换、未保存表单的跨会话恢复、公网部署、全面无障碍审计仍需单独设计和验收。更清楚的界面不等于已具备商业服务的全部账号能力。
