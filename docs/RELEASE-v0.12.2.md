这次把 Windows 演示入口扩展成了一个本地使用包。

下载 **Boxu-Windows-x64.zip**，解压后双击 **Boxu-Windows-x64.exe**。启动窗口可以打开合成演示，也可以建立自己的工作空间；使用者不需要安装 Python、Node.js 或数据库。

演示仍有六种运输阶段的合成订单。自己的空间从空白开始，首次自行设置负责人，项目、账号和附件保存在当前 Windows 用户目录。升级后资料保留；启动窗口也提供完整备份的空库恢复入口。

同时整理了启动配置、账号与空间的接口类型，并增加工程接手说明和独立交付检查。仍需继续整理业务页面类型和历史入口；本次不代表已完成全面工程审计。

当前支持 Windows x64 本机试用，尚未签名。各电脑的数据库彼此独立，员工和货代跨电脑共同使用还需要后续服务端部署。没有飞书或承运商实时接口。发行物不包含作者的账号和工作数据库。

使用包附“先读我.html”、运行许可、第三方通知与摘要文件。具体步骤见 [第一次使用](https://github.com/xuanche2830/boxu-tms-portfolio/blob/main/docs/QUICK-START.html)，维护范围见 [工程接手基线](https://github.com/xuanche2830/boxu-tms-portfolio/blob/main/docs/ENGINEERING.md)。
